## Проблема и результат

Прежний upload-pages-artifact@v5 публикует корень checkout. После объединения
PR33/34 это сделало бы новые local-first приложения доступными онлайн без
отдельного разрешения. В текущем main этих приложений ещё нет: существующий
сайт не объявляется сломанным. Фикстура воспроизводит включение обеих папок
старой GNU tar-командой официального action.

Сборщик создаёт новую staging-папку вне checkout, исключая только корневые
coordinator-demo/ и offline-tools/ сверх прежнего исключения скрытых путей.
docs/platform/, docs/offline-services/, вложенные одноимённые папки и все
остальные прежние публичные файлы сохраняются. Исходники не удаляются и не
редактируются. Символические ссылки отклоняются до копирования, чтобы будущий
alias не вернул исключённые данные в публикацию. В текущей базе ссылок нет.

Проверка сравнивает пути, размеры и SHA-256 каждого файла источника и артефакта.
PR CI строит и проверяет staging; deploy job повторно строит и проверяет её
на собственном checkout и передаёт именно её upload-pages-artifact. Существующие
permissions, environment, расписание и условия запуска workflow не меняются.

Источник поведения скрытых файлов: официальный
https://github.com/actions/upload-pages-artifact/blob/v5/action.yml,
прочитан 17.10.2026. include-hidden-files=false, GNU tar исключает .git,
.github и .[^/]*. Это прежняя граница, не новая чистка публичных ресурсов.

- npm test: 136 passed; генераторы и все штатные валидаторы passed.
- Проверены 14 вакансий, 54 фото, 11 языков каталога и существующая анкета.
- node --check обоих новых скриптов и git diff --check passed.
- До правки все 293 исходных blob совпали с актуальным main; точный tested head,
  итоговый инвентарь/размер и CI записываются в PR.

Команды воспроизведения из checkout (Node >=20, GNU tar):

```sh
npm test
node --test scripts/pages-artifact.test.mjs
artifact_parent=$(mktemp -d)
node scripts/build-pages-artifact.mjs build "$PWD" "$artifact_parent/site"
node scripts/build-pages-artifact.mjs verify "$PWD" "$artifact_parent/site"
```

Выходной каталог должен быть новым, его родитель существовать. Скрипт не удаляет
занятую папку и не перезаписывает её. Запуск проверок не публикует артефакт.
