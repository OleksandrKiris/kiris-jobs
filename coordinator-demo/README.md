# PrimServ — кабинет координатора, demo v0.1.0

**Проверенный изолированный локальный прототип. Только вымышленные задачи. Не CRM и не реестр кандидатов. Не подключён к боту, анкетам или производственным данным; на Pages не публикуется.**

Минимальный сценарий issue [#31](https://github.com/OleksandrKiris/kiris-jobs/issues/31):
три фиксированные задачи DEMO-01/02/03 → статус «К выполнению / В работе / Готово»
→ фильтр → сохранение локального прогресса → повторное открытие.
Нет свободного ввода, сотрудников, персональных данных, отправок или решений по найму.
Это срез направления 7, не завершённый кабинет или реестр знаний.

## Локальный запуск

1. Скачайте **всю папку coordinator-demo/** из точного commit PR. Первый download
   требует интернета. Не смешивайте файлы разных версий.
2. Откройте `index.html` в браузере. Все пять runtime-файлов локальные.
3. Если браузер ограничивает file:// или его хранилище, на собственном компьютере
   из этой папки можно запустить `python3 -m http.server 8080 --bind 127.0.0.1`
   и открыть `http://127.0.0.1:8080/`. Завершение сервера — Ctrl+C.

**Проверен именно file://** в GitHub Actions на точном head PR34 с отключённой сетью. Вариант через localhost HTTP — дополнительная инструкция, его браузерная приёмка не проведена. Никакой онлайн-сервер или публичный адрес этим PR не создаётся.

## Что доступно без сети

После скачивания полного набора файлов логика доски, фильтры, языки и локальные
статусы не используют сеть. Здесь **нет service worker/PWA**, нет обещания SW
на file:// или первого запуска без загруженных файлов. Отключённая сеть проверена в реальном Chromium CI: локальная загрузка, изменение статуса, reload и возврат сети прошли, внешних запросов — 0.
Внешние ссылки PrimServ, вакансий, HYDRA и Telegram требуют интернета и открываются
в новой вкладке, оставляя кабинет на месте. Telegram/HRappka офлайн не обещаются.

RU, UK, PL и EN реализованы в интерфейсе. `?lang=ua` нормализуется в UK,
неподдерживаемый язык показывает EN с явным пояснением. Переход в HYDRA использует
`ua`, в каталог — `uk`. Язык и фильтр сохраняются в URL через replaceState;
при недоступном History API продолжают работать в памяти.

## Хранение и восстановление

- Единственный ключ: `primserv:coordinator-demo:v1`.
- Формат: `{ "version": 1, "statuses": { "demo-01": "todo", "demo-02": "todo", "demo-03": "todo" } }`.
- Сохраняются **только** статусы трёх фиксированных demo-задач при изменении.
  Нет имён, свободного текста, реальных приездов или дат работников.
- Неизвестный/повреждённый формат и недоступное чтение блокируют перезапись.
  Работа продолжается в памяти с видимым предупреждением. Запрет записи не
  уничтожает предыдущую запись. Никакой автоматической миграции/очистки.
- Сброс требует явного подтверждения и удаляет только собственный ключ.
  Если удаление запрещено, интерфейс предупреждает, что оно не гарантировано.
- file:// и приватный режим могут ограничивать localStorage. Не рассчитывайте
  на перенос данных между браузерами, устройствами или разными URL запуска.
- После обновления сохраняйте тот же локальный путь/origin. Текущий v1 совместим
  с тем же набором ID; неизвестные будущие форматы намеренно не преобразуются.
